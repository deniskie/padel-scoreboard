# Padel Scoreboard

Large court-side scoreboard (iPad) for matches tracked with the Garmin apps **Padel Smash** or **Tennis Smash**.

Open `index.html?app=padel&pin=<6-digit PIN>` (or `app=tennis`) and tap *Show scoreboard*.

- Live updates via the public realtime channel used by padelsmash.app / tennissmash.app (`match-<PIN>`)
- Serving team highlighted, serve side derived from the point count
- English score announcements (toggle), screen stays awake

Unofficial: relies on the public endpoints of padelsmash.app and tennissmash.app, which may change at any time.
